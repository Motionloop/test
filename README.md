# Simple Calculator

A basic command-line calculator that supports fundamental arithmetic operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Input validation
- Error handling (e.g., division by zero)

## Usage

Run the calculator:

```bash
python3 calculator.py
```

Or make it executable:

```bash
chmod +x calculator.py
./calculator.py
```

## Example

```
========================================
Simple Calculator
========================================

Operations:
1. Add (+)
2. Subtract (-)
3. Multiply (*)
4. Divide (/)
5. Exit
========================================

Select operation (1-5): 1
Enter first number: 10
Enter second number: 5

10.0 + 5.0 = 15.0
```

## Requirements

- Python 3.x
